# Meu Portfólio Pessoal 👨‍💻

> Um site de portfólio desenvolvido para apresentar minhas habilidades, projetos e formas de contato.

## 💻 Sobre o Projeto

Este projeto foi construído durante meus estudos de desenvolvimento Front-end (focado em HTML e CSS) na Alura. O objetivo é criar uma vitrine profissional para apresentar as soluções que construo, conectando o mundo do desenvolvimento web com as minhas outras áreas de atuação.

## 🚀 Sobre Mim

Sou José Arthur (também conhecido como Touro), estudante de Inteligência Artificial na UFPE e entusiasta da tecnologia como um todo. 

Além de mergulhar no desenvolvimento Front-end para criar interfaces web incríveis e funcionais, possuo uma forte vivência na área de hardware, automação e robótica.
